# AgentMemoryBar

Небольшое приложение для строки меню macOS, которое управляет локальным **[agentmemory](https://github.com/rohitg00/agentmemory)**.

🟢 Сервер работает · ⚪ Выключен · 🟠 Выполняется действие · 🔴 Требуется внимание

## Установка

Нужны macOS 13+, Node.js 20+ и отдельно установленный и настроенный agentmemory.

1. Скачайте DMG из Releases, перенесите приложение в Applications и извлеките образ.
2. Откройте AgentMemoryBar из Applications.
3. В меню значка включите **Launch app at login** для автозапуска после входа в macOS.

Сборка по умолчанию подписана локальной подписью, без нотариализации Apple. macOS может потребовать открыть её через «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть». Сначала проверьте исходники и контрольную сумму. Не отключайте защиту macOS целиком.

## Как работает автозапуск

**Вход в macOS → AgentMemoryBar → agentmemory.** Отдельного автозапуска сервера нет. Приложение запускает его один раз при открытии, если вы ранее не выключили сервер через меню.

| Команда | Что делает |
| --- | --- |
| Start agentmemory | Запускает сервер и разрешает запуск при следующем открытии приложения. |
| Stop agentmemory | Останавливает сервер и сохраняет выбор между перезагрузками. |
| Restart server | Штатно перезапускает сервер. |
| Launch app at login | Включает или выключает автозапуск самого значка. |
| Open memory viewer | Открывает веб-интерфейс памяти. |
| Settings… | Позволяет указать путь к Node.js/CLI и каталог данных. |
| Quit AgentMemoryBar | Закрывает значок; сервер продолжает работать. |

Ежеминутных проверок и постоянного автоматического восстановления нет. Статус обновляется при открытии меню, изменении файлов состояния, завершении процесса и пробуждении Mac. Если запуск не удался — проверьте журнал и повторите вручную.

Выключение сервера не удаляет память и не отключает hooks в клиентах: они могут сохранять события в локальную очередь.

Приложение поддерживает стандартный локальный Compose instance на портах 3111/3113. Проверено с agentmemory 0.9.33 на Apple Silicon. Intel включён в универсальную сборку, но требует проверки на Intel Mac.
